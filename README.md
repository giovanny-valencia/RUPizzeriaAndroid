# RU Pizzeria Android App
Rutgers Software Methodology CS213 Project #4

Giovanny Valencia (gv206) and Miguel Nino Adalla (mva54)

## Project Description
The **RU Pizzeria Android App** is a mobile adaptation of the original **RU Pizzeria** project,
which was previously implemented as a JavaFX desktop application for **CS213 Project #4**.

This Android application is designed to provide **pizzeria employees** with a seamless, user-friendly interface
to efficiently create, manage, and finalize pizza orders. With its intuitive design and mobile-focused functionality,
the app streamlines the ordering process and enhances productivity in a theoretical pizzeria setting.

## Notes

To maintain a minimalistic design, an official Toolbar/Title was not implemented since the project was created with the "No Activity" 
template instead of the "Empty Activity" template. Following a discussion with Professor Chang, it was determined that including a toolbar was not mandatory, 
provided users could navigate back to the previous activity.

For simplicity, some activities do not include explicit back buttons but allow navigation using Android's native gestures, 
such as swiping from the left edge of the screen to go back. This design choice prioritizes a clean user interface while preserving functional backward navigation.
